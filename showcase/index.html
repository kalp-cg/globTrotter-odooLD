🚀 Deployment Playbook: Render (Backend) & Vercel (Frontend)

🌐 1. Backend Service on Render

Web Service deployment with Node.js and PostgreSQL connection.

Root Directory: backend
Build Command: npm install && npm run build
Start Command: npm start
Environment Variables:
- DATABASE_URL (PostgreSQL connection string)
- JWT_SECRET (Session security token)
- CORS_ORIGIN = *

⚡ 2. Frontend App on Vercel

Next.js 16 App Router optimized for global CDN edge deployment.

Root Directory: frontend
Framework Preset: Next.js
Build Command: next build
Output Directory: .next
Environment Variables:
- NEXT_PUBLIC_API_URL (Render backend URL e.g. https://your-backend.onrender.com)
